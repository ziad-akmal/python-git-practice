# python-git-practice

A small Python quiz project created to practise Python fundamentals and Git/GitHub workflows.

## Project

The project is a simple terminal-based quiz where the user answers multiple-choice questions and receives a final score.

## Git Practice

This repository was also used to practice different Git workflows, including:

* Creating commits for separate changes.
* Creating and switching between branches.
* Making changes on different branches.
* Merging branches into `main`.
* Switching to previous commits using commit hashes.
* Restoring the project to an earlier point in its history.
* Deleting branches after merging.
* Connecting a local repository to a GitHub remote.
* Pushing the local `main` branch to GitHub.
* Understanding merge conflicts and how to resolve them.

## Purpose

The main goal of this project was not only to build a simple Python program, but also to understand how Git tracks changes and how different versions of a project can be managed safely.
